# Je verbs

Веб-приложение для автоматизации базовых французских `je`-форм уровня A1-A2.

## Live

- GitHub Pages: <https://polpal1623.github.io/JeVerbs/>
- Репозиторий: <https://github.com/PolPal1623/JeVerbs>

## Что внутри

- 10 базовых глаголов: `être`, `avoir`, `aller`, `faire`, `dire`, `devoir`, `pouvoir`, `vouloir`, `savoir`, `prendre`.
- 5 времён: `présent`, `futur proche`, `passé composé`, `imparfait`, `futur simple`.
- Только формы с местоимением `je`.
- Карточка каждого глагола с таблицей форм, короткими примерами и TTS.
- Тренировка: flashcards, reverse mode и ввод ответа.
- Мини-тесты на 5 или 10 вопросов: выбор, ввод и сопоставление.
- Упрощённое интервальное повторение, режим сложных форм, локальный прогресс и streak.

## Запуск

Откройте `index.html` в браузере. Приложение работает офлайн и не требует сборки.
